# ☕ Morning_Coffee (Онлайн-газета)

Автоматизированный генератор регулярной онлайн-газеты в формате PDF. Проект собирает актуальную информацию с нескольких источников, формирует красиво сверстанный выпуск и отправляет его по запросу на электронную почту.

## 🎯 О проекте
**Morning_Coffee** — это скрипт, развернутый на сервере, который автоматически парсит данные и генерирует PDF-выпуски газеты по адаптивному расписанию:
- Каждые **30 минут** в утренние часы (06:00 – 10:00);
- Каждые **1,5 часа** в дневное время (10:00 – 23:00);
- Каждые **3 часа** в ночное время (23:00 – 06:00).

Параллельно скрипт проверяет почтовый ящик проекта каждые 2–5 минут. Если он находит непрочитанное письмо, в теме которого содержится слово **«газет»** или его производные (вне зависимости от регистра), он автоматически отправляет отправителю ответное письмо с прикрепленным актуальным PDF-выпуском.

## 📰 Содержание выпуска
Каждый PDF-файл содержит структурированную информацию:
- Приветствие с текущей датой и днем недели;
- Прогноз погоды на текущий день (с иконкой и фазами луны);
- Гороскоп на текущий день для всех знаков зодиака;
- Актуальные курсы валют (USD, EUR, CNY);
- Новости общества и политики (до 8 актуальных материалов);
- Новости науки и технологий (до 8 актуальных материалов);
- События, произошедшие в этот день в прошлом («День в истории», до 8 фактов);
- Свежие новости непосредственно в сфере IT-разработки.

## 🌐 Источники данных
Информация собирается и обрабатывается со следующих ресурсов:
1. **Центральный Банк РФ** — курсы валют;
2. **Foreca.com** — прогноз погоды;
3. **Радиостанция «Европа Плюс Россия»** (API) — гороскоп;
4. **Радиостанция «Бизнес-ФМ Россия»** — новости общества и политики;
5. **Naked-science.ru** — наука и технологии;
6. **Calend.ru** — день в истории;
7. **Tproger.ru** — новости IT-разработки.

## 🚀 Запуск и использование
### Требования
- Python 3.11 или новее.
- Системные зависимости для `WeasyPrint` (Pango, Cairo, GDK-PixBuf и др.).
- Файл `keys.txt` в корневой папке проекта, содержащий в первой строке email аккаунта, а во второй — пароль приложения (каждая строка без лишних пробелов).

### Установка зависимостей
Создайте файл `requirements.txt` со следующим содержимым и установите пакеты:
```text
requests
beautifulsoup4
jinja2
weasyprint
```
```bash
pip install -r requirements.txt
```
### Инструкция по запуску
* Клонируйте репозиторий или скачайте файлы проекта.
* Убедитесь, что файл keys.txt создан и заполнен корректными данными.
* Запустите основной скрипт: python3 main.py

### Как получить выпуск
Просто отправьте письмо на адрес public32@yandex.ru со словом «газета» (или «газету», «газеты») в теме письма. В ответ вы автоматически получите свежий PDF-выпуск.
